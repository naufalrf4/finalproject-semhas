Metode · Arsitektur Sistem ELSA

Empat lapisan: dari sensor di akuarium sampai notifikasi di ponsel pengguna.

1
Perangkat
ESP32-S3 pH Suhu DO TDS

Bila WiFi putus, data disimpan dulu di perangkat lalu dikirim ulang saat online.

2
Komunikasi
Firebase RTDB Login API Backfill

Data dikirim ke cloud secara near real-time agar dashboard selalu menampilkan kondisi terkini.

3
Aplikasi web
Next.js Indeks risiko Notifikasi

Hitung indeks, tampilkan dashboard, kirim WhatsApp / Telegram / PWA saat kategori berubah.

4
Penyimpanan
RTDB live Firestore TimescaleDB

Berjenjang: cepat untuk live, arsip jangka pendek, dan deret waktu untuk analisis 103 hari.
